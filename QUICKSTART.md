# Quickstart

```sh
git clone <repo-url> superchat && cd superchat
./scripts/setup.sh
```

Then open the address it prints (default `http://127.0.0.1:5173`). The first account you register
becomes the deployment owner.

- Architecture, services and overlays: [README](./README.md#run-with-docker).
- Prerequisites, models, backups, troubleshooting: [docs/SETUP.md](./docs/SETUP.md).
