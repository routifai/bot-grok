# Deck charts are Chart.js, exported as native PowerPoint charts

An HTML deck (ADR 0011) exported its charts as HTML and CSS shapes, and the native PowerPoint path (ADR 0012) was the only way to a chart with Edit Data. People who ask for a designed deck also want its charts to be real charts.

- **Chart.js on a canvas, as Open Design ships it.** A chart slide is the `l-chart` layout with one of Open Design's chart recipes (bar, line, doughnut, radar, ported as written, plus a bar-and-line combo): Chart.js 4.4.3 on a `<canvas>`. Chart.js is vendored into every deck (MIT, pinned), so a deck works offline and under the viewer's CSP. The one script a slide may carry is the chart's `<script data-nova-chart>`.
- **Read the chart, write a native chart.** At export the page reads each Chart.js instance as configured (type, labels, datasets, colors, axis min/max/step, legend, title, `ticks.format` number formats) and puts a PptxGenJS chart spec on its canvas (`data-pptx-chart`). A small hook in a pinned build of dom-to-pptx 2.0.1 adds it with `addChart` at the canvas box, keeping z-order, so the file holds a `c:chart` part with an embedded workbook. Bar (clustered, stacked, horizontal), line, area, pie, doughnut, radar, scatter, bubble and a bar-with-line combo on two axes are supported: every type both libraries have natively.
- **No picture fallback.** A chart with no PowerPoint equivalent (`polarArea`, a gauge, several doughnut rings, a stacked line, a canvas that is not Chart.js) fails `deck_check` and the export with a sentence naming the slide, so the Muse picks a native type or a table. The same hook gives tables their rendered row heights.
- **Data comes from the person's files.** The deck rules require chart and table numbers to be computed with pandas in the Computer and the caption to cite the file and columns.

## Considered options

- **Draw the chart from HTML/CSS shapes.** Rejected: not a chart in PowerPoint.
- **Rasterize the canvas.** Rejected: a picture, not editable.
- **Hand-edit the vendored bundle.** Rejected: the bundle is rebuilt from upstream source plus a documented patch (`vendor/dom-to-pptx/README.md`).

## Consequences

- The Computer image needs a rebuild (page module, bundle); the engine needs a restart (kit, menu, `deck_check`); the prompt bundles are regenerated by `node infra/omnigent/render-agents.mjs`.
- Every deck carries about 200 KB of Chart.js.
- The bundled PptxGenJS carries the same fixes as the Computer's (ADR 0012).
